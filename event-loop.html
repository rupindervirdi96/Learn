1. The V8 Engine

V8 is a C++ program inside Chrome & Node.js. It reads your JS and turns it into machine code the CPU can run.

Mental Model

  • V8 = the translator. Your JS is a recipe in English; V8 converts it to what the CPU speaks.
  • JIT (Just-In-Time) means V8 compiles code as it runs — hot paths get faster over time.
  • The Heap is V8's memory warehouse — where all your objects and variables live.
  • The Call Stack is also inside V8 — it tracks which function is currently running.

2. Synchronous vs Asynchronous

JS is single-threaded — only one thing runs at a time on the Call Stack. Async is how it avoids getting stuck waiting.

⛔ Synchronous — Blocking

console.log("1. Start");

// This BLOCKS the whole thread!
for (let i = 0; i < 3_000_000_000; i++);

console.log("2. End");

// Output: 1 ... (long freeze) ... 2
// Nothing else can run during the loop!

✅ Asynchronous — Non-blocking

console.log("1. Start");

// Handed off to Web API — stack is free!
setTimeout(() => {
  console.log("3. I waited 1s");
}, 1000);

console.log("2. End"); // runs immediately!

// Output: 1 → 2 → (1 sec) → 3
// "2" prints BEFORE "3"!

3. The Event Loop — Interactive

The event loop's one job: "Is the Call Stack empty? If yes, move the next queued task onto it." Microtasks (Promises) always run before Macrotasks (setTimeout).

The Order:

  • Call Stack first. All synchronous code runs here, top-to-bottom, right now.
  • setTimeout / fetch → Web API → Macrotask Queue. These wait until the stack is empty.
  • Promise.then → Microtask Queue. Runs before any macrotask, after each stack drain.
  • Loop: Stack → drain all Microtasks → one Macrotask → drain all Microtasks → repeat.

4. The Golden Rule — Memorize This

console.log("1");                     // sync → stack → prints 1st
setTimeout(() => console.log("2"), 0);      // macro → queue → prints LAST
Promise.resolve().then(() => console.log("3"));  // micro → queue → prints 3rd
console.log("4");                     // sync → stack → prints 2nd
Output: 1 → 4 → 3 → 2

Open browser DevTools (F12 → Console) and paste this to verify!
